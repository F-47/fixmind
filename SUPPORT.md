# Support

Fixmind is a solo-maintained project. Support is provided on a best-effort basis; no response or resolution time is guaranteed unless a separate written service agreement says otherwise.

## Where to ask

- Public-product bugs and feature requests: use the public GitHub repository's issue tracker after launch. Search existing issues first and include the affected version, operating system, reproduction steps, and relevant non-sensitive logs.
- Installation, account, billing, hosted-sync, or private-data questions: email `support@fixmind.dev`.
- Security vulnerabilities: follow `SECURITY.md`. Do not open a public issue.
- Conduct incidents: follow `CODE_OF_CONDUCT.md`. Do not open a public issue.

While the repository remains private, use `support@fixmind.dev` instead of GitHub issues.

## Support boundaries

Maintainers can help diagnose Fixmind itself but cannot provide support for unrelated applications, operating-system administration, or third-party services. Never send passwords, access tokens, signing keys, full lesson databases, or source code from unrelated private projects.

Local Fixmind functionality does not require a paid support plan. Hosted-service availability, data retention, recovery, refunds, and any future service-level commitments are governed by the applicable hosted-service terms, not this file.
